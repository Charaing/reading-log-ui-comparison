# 독서 기록 UI 비교

같은 요구사항("독서 기록 모바일 웹앱")으로 만든 두 버전입니다.

- [without-skill.html](https://charaing.github.io/reading-log-ui-comparison/without-skill.html) — `production-grade-ui` 스킬 없이 생성
- [with-skill.html](https://charaing.github.io/reading-log-ui-comparison/with-skill.html) — 스킬의 작업 순서(토큰 선언 → 구조 → 상태 → 렌더링 검수)를 따라 생성

책 목록은 예시 데이터이며, 기록은 브라우저(localStorage)에만 저장됩니다.
